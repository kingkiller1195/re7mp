Installation:

https://www.youtube.com/watch?v=3M1CG62zraA

1. Have Tailscale or a similar VPN client like radmin that you can use to share IP's in a LAN.

2. Install reframework into the game folder.

3. Run the EXE file and press install Lua script (EXE might give blue prompt, just press more info and run anyway, this is because it is unsigned atm)

4. Choose Network at the top of the window and choose whether to Host or join (only joiner has to put host ip:port).

5. Press START and make sure the game is loaded and it should say the other players position and where they are, press new game and select whatever difficulty you wish

   To run this game on steamos (Steamdeck) or linux, you can use the same VPNs on windows and instead of just running the re7mp.exe you add a non steam game and run it through proton or wine. I have tested with the Steamdeck and this does work.
