autostrong_test_encrypted.bin / autostrong_test_decrypted.bin are the two 212-byte test files from AutostrongSharp
(https://github.com/mi5hmash/AutostrongSharp, QualityControl.xUnit/Resources), copyright (c) 2026 Michal Gebicki, MIT License.
They belong to a test game profile, not to RE7. They are used only to check that this project's Murmur3 signature code gives the same
signature as the original tool's on real files (the encrypted one carries the signature the original tool wrote).
Sorry for the missing accents in the name; the file is ASCII.
